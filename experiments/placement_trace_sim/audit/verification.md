## 3. 模型与策略审计

| 审计项 | 结论 | 影响与必要修正 |
|---|---|---|
| 预测信息泄露 | 通过 | Cost-aware 在窗口 (t) 只用窗口 (t-1) 的 Trace、计数和上一窗口 GPU 负载估计候选成本；当前窗口只在动作确定后评估，没有读取当前热点。 |
| 动作与状态转移 | 通过，需明确累计语义 | Sample placement 和副本状态会保留到下一窗口；样本只对实际变更的样本计求解/映射成本，副本计激活、移除和每个活动副本的同步成本。Cost-aware 每个窗口在 Keep、Sample placement、Expert replication 三个互斥候选中选一个，但历史状态可以跨窗口累计，因此不能称为同一窗口内已验证的联合优化。 |
| 公平输入 | 通过 | 每个场景—seed 的 12 × 32 × 16 = 6,144 个 Top-1 Token 对所有策略相同；`cross_node_tokens` 与机内 Token 互补，副本只改变请求的执行位置，不删除专家工作。 |
| 指标语义 | 通过，字段名需谨慎解释 | `peak_expert_or_gpu_load` 实际是单个窗口内最大 GPU 接收 Token 数，可能包含多个专家，不是单一专家峰值；`cross_node_tokens` 是 Token 计数，不是尾时延；`cost_proxy` 不是 Step Time。正文和本记录均按此解释。 |
| 成本模型 | 通过，范围受限 | 代码实现 `T_proxy = 2 × (跨节点 Token × 1.0 + 机内 Token × 0.20) + 0.80 × 峰值 GPU Token + 调整成本`。它是无 overlap 的串行相加模型；样本放置不额外计一次独立 Token 搬运，副本激活、移除和同步按代码规则计入。分项和总和的最大舍入误差为 0.0001。 |
| 策略定义 | 通过，不能过度解释 | Cost-aware 是上一窗口信息驱动的候选选择器，不是 oracle，也不是已验证的复杂联合控制器；其跨窗口保留状态的行为已在场景 C 诊断中显式记录。 |

未发现影响结果的程序错误，因此没有生成 `simulate_checked.py`，也没有修改原实验生成器或成本参数。

### 4.1 根因拆解

1. **主要原因是历史路由信息过时。** 当前热点序列为 `E0 → E4 → E2 → E6` 循环，热点每个窗口改变，并在节点 0 与节点 1 之间交替。样本放置依据上一窗口的专家计数，使当前布局追随上一热点；例如窗口 1 上一热点为 E0、当前热点为 E4，预测时样本放置比 Keep 低 682.88 对 840.80，但在真实当前窗口中反而为 1012.48 对 860.00。
2. **专家复制不是本次 Cost-aware 负结果的直接原因。** C 场景中 Cost-aware 的复制候选在每个窗口都没有被选中，因而最终没有活动副本；Cost-aware 与 Sample placement 的动作计数和逐窗口成本完全一致。复制候选同样使用滞后的上一窗口信息，但其激活与同步代价使预测成本通常高于样本放置。
3. **重配置成本是次要因素，而非主因。** seed=11 中 Cost-aware 相对 Keep 的平均跨节点 Token 增加 97.50，通信代理增加 156.00；峰值 GPU 负载均为 291.25，专家计算代理没有变化；平均调整成本仅增加 5.8533，总代理增加 161.8534。因此不能把 C 的负结果主要归因于样本求解费用。
4. **没有发现特殊计费错误。** 逐窗口的通信代理、专家代理和调整成本之和与总成本代理一致；Keep 反事实使用同一 Trace 和动作前状态；所有策略的 Token 总数相同。因此 C 的负结果是“上一窗口预测在快速漂移下失效”的模型现象，而不是漏算或多算 Token。

本次没有额外做参数敏感性调优。逐窗口的预测—反事实—实际三者已经能区分过时预测、通信增量和调整成本；继续调参到让 Cost-aware 获胜会改变问题，而不能增加对现有负例的解释力。

## 6. 学术边界

本实验没有复现 Janus、FlexMoE、SYMI 或 NetMoE 的真实系统，也没有使用真实 GPU、InfiniBand、Ethernet、交换机队列、CUDA/NCCL 或训练框架。它只能支持如下有限判断：在给定合成 Trace 和相对成本模型下，局部性强时样本放置可能降低通信代理，热点稳定时复制可能降低峰值 GPU Token 负载，而热点快速漂移时依赖上一窗口的 Cost-aware 选择可能劣于 Keep。真实训练加速、吞吐、尾时延、Token dropping、精度和收敛收益仍需后续端到端实验验证。
